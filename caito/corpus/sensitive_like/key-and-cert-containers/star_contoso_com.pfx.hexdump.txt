# PKCS#12 (.pfx / .p12) bundles a cert + its private key, usually passphrase-
# protected. BINARY. Common paths: IIS export folders, C:\certs,
# %USERPROFILE%\Documents, and code-signing key stores.
# Identify by the ASN.1 SEQUENCE header (30 82 ..) and the OID for pkcs-12.
#
# `xxd star_contoso_com.pfx | head` (SYNTHETIC header, real structure):

00000000: 3082 0a3b 0201 0330 8209 f706 092a 8648  0..;...0.....*.H   <- 30 82 = SEQUENCE; 02 01 03 = version 3
00000010: 86f7 0d01 0701 a082 09e8 0482 09e4 3082  ..............0.   <- OID 1.2.840.113549.1.7.1 (pkcs7 data)
00000020: 09e0 3082 060f 0609 2a86 4886 f70d 0107  ..0.....*.H.....
00000030: 06a0 8206 0030 8205 fc02 0100 3082 05f5  .....0......0...   <- encryptedData (the key, pw-wrapped)
00000040: 0609 2a86 4886 f70d 0107 0130 1c06 0a2a  ..*.H......0...*
00000050: 8648 86f7 0d01 0c01 0630 0e04 08fa ke01  .H.......0......   <- pkcs-12 pbeWithSHAAnd3-KeyTripleDES-CBC
00000060: 2233 4455 6677 8899 0201 0800 8205 c8fa  "3DUfw..........
#
# pfx2john star_contoso_com.pfx ->
# star_contoso_com.pfx:$pkcs12$1*3*2*20*fake0123456789abcdef*...  (crack the passphrase offline)
#
# If the passphrase is known/empty:
#   openssl pkcs12 -in star_contoso_com.pfx -nodes -out out.pem   (dumps key+cert in cleartext)
