# KeePass databases (.kdbx) are BINARY and encrypted with the master key.
# Common paths: Desktop, OneDrive, C:\Users\jdoe\Documents\Database.kdbx.
# You can't read entries without the master password / key file, but the file
# is instantly identifiable by its magic signature, and the KDF params are
# readable in the header (useful for offline cracking via keepass2john/hashcat).
#
# `xxd Database.kdbx | head` (SYNTHETIC header, real structure):

00000000: 03d9 a29a 67fb 4bb5 0100 0300 0200 1000  ....g.K.........   <- 03 D9 A2 9A = KeePass magic; 67 FB 4B B5 = KDBX v2 sig
00000010: 31c1 f2e6 bf71 4350 be58 05f5 4dff 03a8  1....qCP.X..M...   <- cipher UUID (AES-256-CBC)
00000020: 0200 0400 0100 0000 0300 2000 8f2a1c7d3e  .......... .*.}>   <- compression + master seed
00000030: 5b60 9481 f2c3 d4e5 f607 1829 3a4b 5c6d  [`.........):K\m
00000040: 7e8f 0e1d 2c3b 4a59 6877 0b00 0800 4000  ~...,;JYhw....@.   <- KDF rounds
00000050: 0000 0000 0000 000c 0004 0000 0002 0000  ................
#
# keepass2john Database.kdbx  ->
# Database:$keepass$*2*60000*0*8f2a1c7d3e5b609481f2c3d4e5f60718*...fakehash...
