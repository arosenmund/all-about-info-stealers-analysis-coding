# 05 · Writing an InfoStealer

**Lead:** Aaron · **Time:** 45 minutes

## Goal

Turn analysis observations into a constrained proof of concept that operates only on synthetic workshop artifacts inside the isolated range.

## Lab flow

1. Review the provided, safety-scoped code snippets.
2. Map each component to a behavior observed during analysis.
3. Add the instructor-directed functionality.
4. Compile and run the code in the lab.
5. Inspect the controlled output.


## Guardrails

The exercise must remain inside the assigned lab, use only provided synthetic data, and follow instructor checkpoints. Do not add persistence, evasion, credential access, or external transmission capabilities.
