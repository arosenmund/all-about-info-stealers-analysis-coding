# 01 · Welcome & Orientation

**Lead:** Ryan + Aaron · **Time:** 10 minutes

## Where we are going

We will learn how information stealers work twice: first by taking one apart, then by translating what we observe into a controlled proof of concept. The final module introduces local relevance scoring as an alternative to broad, hard-coded collection.

By the end of the workshop, you should be able to:

- describe the major stages of modern InfoStealer behavior;
- navigate and annotate relevant logic in Ghidra;
- connect reverse-engineering observations to implementation choices;
- compile and test workshop code inside an isolated range; and
- compare static targeting with model-assisted relevance scoring.

## How we will work

- Participate actively and ask questions early.
- Be patient and respectful—experience levels will vary.
- Follow the instructors' checkpoints before running an exercise.
- Keep all samples, credentials, and generated data inside the lab.
- Only test systems you own or are explicitly authorized to assess.

## Workshop flow

`Analyze → Model → Build → Test → Compare`

Ryan leads the analysis half using LummaC2 as the case study. Aaron leads the implementation half in the OnDefend lab. The goal is understanding behavior and defensive implications, not deploying malware.

## Quick check

Before moving on, confirm that you have a laptop, Wi-Fi, a modern browser, and access to this repository.
